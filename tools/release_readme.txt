Pelota - a tennis simulation game (alpha)
https://github.com/mbkma/pelota

This is an early alpha: expect bugs and missing features.
Report problems at https://github.com/mbkma/pelota/issues


STARTING THE GAME

Linux:    run ./Pelota.x86_64 (or double-click it)
Windows:  double-click Pelota.exe
          Windows SmartScreen may warn about an unknown publisher because the game is not
          signed: click "More info", then "Run anyway".

A graphics card with Vulkan (Linux, Windows) or Direct3D 12 (Windows) support is required.


CONTROLS

                    Keyboard            Gamepad
Move / aim          W A S D, arrows     Left stick, D-pad
Topspin / flat      Space               A
Slice               Shift               X
Drop shot           Ctrl                Y
Pause               Esc                 Start

Rally: press a stroke button early, the player runs to the ball by itself. Aim with the
direction while holding, release just before the ball reaches the racket for a perfect shot.

Serve: hold a stroke button (Space flat, Shift slice, Ctrl kick) and aim into the service box,
release to toss the ball, then press any stroke button again right before the racket meets
the ball.
